# 美国 PPI → CPI 传导滞后分析

分析美国近 24 个月（2024-06 ~ 2026-05）生产者价格指数 (PPI) 与消费者价格指数 (CPI) 之间，
是否存在“工业/生产端 → 消费端”的滞后传导链条。

## 数据
- **CPI**：`CPIAUCSL`（All items，全项）— `cpi.csv`
- **PPI**：`PPIFIS`（Final Demand，最终需求）— `ppi.csv`
- 来源：FRED / 美国劳工统计局 (BLS)
- 注：数据源中 2025-10 的 CPI 缺失，脚本用前后两月线性插值处理。

## 方法
`analyze.py` 计算：
1. 指数水平、同比 (YoY)、环比 (MoM)
2. 把 PPI 前移 0–6 个月后，与当月 CPI 做皮尔逊互相关，找相关系数峰值对应的滞后期

运行：`python3 analyze.py`

## 结论
**存在滞后传导规律，属于“温和领先”。**

- 同比口径下，互相关峰值落在 **滞后 2–3 个月**（r≈0.93），即 PPI 变化平均领先 CPI 约 2–3 个月；
  月环比平滑后峰值在 **滞后 0–1 个月**，领先更短、更嘈杂。
- 当下是活教材：2026-02 起 PPI 同比从 3.4% 陡升至 5 月的 6.4%，CPI 同比同期从 2.4% 跟涨到 4.2%，
  生产端先冲高、消费端滞后跟进。
- 注意：传导非 1:1。PPI 波动大于 CPI（服务、房租等 CPI 权重项与工业品价格关系弱），
  相关性高有一部分来自共同趋势，样本量有限，勿过度外推。

交互式可视化报告见 `index.html`。
