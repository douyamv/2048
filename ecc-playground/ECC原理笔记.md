# 椭圆曲线密码学 (ECC) 原理笔记

从"以太坊私钥能不能撞出小地址"出发，一路推到椭圆曲线的底层原理。
本目录的脚本都可直接运行，用一条 `y² = x³ + 7` 的**迷你曲线**（和以太坊同方程，
只是素数 p 很小）来动手验证每一个结论。

## 文件

- `break_toy_ecc.py` —— 玩具曲线 + 两种离散对数破解（BSGS / Pollard's rho）+ 规模演示
- `plot_curve.py` / `ecc_curve.png` —— 连续曲线 / 点加法几何 / mod p 离散点云
- `plot_walk.py` / `ecc_walk.png` —— 在点云上把 G→2G→…→12G 连线（含折叠次数）
- `plot_gallery.py` / `ecc_gallery.png` —— 曲线画廊：形状由 `4a³+27b²` 符号决定
- `plot_curve.py` 里的 nose 演示 / `ecc_nose.png` —— "鼻子"位置 = −∛b
- `complex_view.py` —— 复数视角：三个复根 + GLV 自同态（CM 结构）

## 核心结论

### 1. 私钥与公钥的本质

- **私钥 = 走过的步数 k**（一个 `0 ~ n-1` 的整数）
- **公钥 = 从基点 G 走 k 步的落点**，曲线上的一个整数点 `(x, y)`
- `Q = k·G = G + G + ... + G`（加 k 次）

### 2. 点加法

- 含义：**步数相加**。`i·G + j·G = (i+j)·G`
- 几何：过两点作直线 → 取**第三个交点** → 沿 x 轴**翻转**
- 封闭性：直线与三次曲线恰好交于 3 点，已知 2 点则第三点被唯一确定且必在曲线上
- `x₃ = s² − x₁ − x₂` 来自三次方程的**韦达定理**（三根之和 = s²）
- 翻转的原因：让这些点构成一个**群**（零元 = 无穷远点，满足结合律）；
  群法则"共线三点之和 = 零元" ⟹ `P+Q = −R`，而 `−R` 是 R 关于 x 轴的镜像

### 3. 循环群

- 曲线上共约 n 个点（有限），首尾相连成环
- 走 n 步回到起点（无穷远点 = 零元），所以步数是 **mod n** 循环的

### 4. 安全性的来源

- **正向**（k → Q）容易：double-and-add，约 log₂(k) 步
- **反向**（Q → k）极难：离散对数，无捷径
- mod p 把光滑曲线**粉碎打乱**成无序点云：相邻步数落点天南海北，**没有连续性**
  → 浮点数 / 微积分 / 牛顿法等连续方法全部失效（"接近"在这里毫无意义）
- 暴力破解 ≈ n 次；最优算法（BSGS / Pollard's rho）≈ √n 次
- 迷你曲线 √n 只有几十 → 秒破；secp256k1 的 √n ≈ 2¹²⁸ → 跑到宇宙终结也破不了
- index calculus（亚指数攻击）对"模 p 乘法群 / RSA"有效，但对椭圆曲线**无效**
  —— 这正是 EC 每比特强度远高于 RSA、256 位就够用的根本原因

### 5. 曲线形状（实数视角）

- 方程 `y²=x³+ax+b`，形状由 `D = 4a³+27b²` 决定：
  - `D > 0` → 一个实根 → **单块**（"花瓶/号角"，如以太坊 a=0,b=7，D=1323）
  - `D < 0` → 三个实根 → **两块**（左边一个孤立椭圆环 + 右边开放臂）
  - `D = 0` → **奇异曲线**（尖点 cusp / 结点 node），群运算会崩，密码学必须排除
- "鼻子"（最左点，竖直切线处）位置 = `−∛b`；`+b` 把它推到 x<0
- **实数形状与密码学无关**：真实运算在 mod p 上，无论单块还是两块，
  mod p 后都是 ≈ p 个散点、铺满全域。决定能否用的是"非奇异 + 大素数阶"，不是形状

### 6. mod p 的"折叠"

- `fold = (x³+7) // p`，即算这个点时 x³+7 跨过了多少个 p 的倍数
- 范围 `0 ~ p²`；因为是立方，fold ≈ x³/p，小 x 处被"压扁"，只有 x 接近 p 才逼近 p²
- 折叠次数与"第几步（私钥）"之间完全无序 → 对破解没有任何帮助

### 7. 快速标量乘（正向加速，反向无效）

- **double-and-add**：把 k 按二进制拆，翻倍 ≈ log₂(k) 次 + 加法 ≈ k 的 1-比特数。
  256 位 ≈ 256 倍 + 128 加 ≈ 384 次点运算（vs 朴素 2²⁵⁶ 次）
- **每次点加法内含一次除法**（算斜率的模逆元）；"加 G 几次" = 做几次除法
- **固定基点预计算**：G 固定 → 预存 `2ⁱG`，算时只做加法
- **存储↔速度权衡**（窗口法）：加法 ≈ 256/w，存储 ≈ (256/w)·2^w，
  速度线性涨、存储指数涨，甜点 w=4~8（几十~几百 KB）
- **w-NAF**：利用"−P 免费（翻转 y）"用带符号位 `{−1,0,1}`，让非零位更稀疏
  → 省加法；适合**变动基点**（如验签时的公钥）
- **comb (Lim–Lee)**：把 k 排成 `h 行×a 列` 网格，竖着扫，每列翻倍 + 查表加。
  翻倍只需"列数"次，表仅 `2ʰ` 个点（与位数无关）→ 省存储；适合**固定基点**
- **理论下限** ≈ log₂(k) ≈ 256（每次翻倍最多翻一倍，达到 2²⁵⁶ 至少 256 次）
- **常数时间 / 防侧信道**：comb 步数恒定（翻倍-加-翻倍-加…），与 k 无关 →
  时序/功耗曲线不泄露私钥比特。普通 double-and-add"按位决定加不加"会泄露私钥

### 8. 复数 / 环面视角（最深层结构）

- `x³+7=0` 在复数下恰好 3 个根（1 实 + 2 共轭复），对应 3 个 2-阶挠点（y=0）
- **在 ℂ 上，整条椭圆曲线 = 一个环面（甜甜圈）** `ℂ/Λ`；
  那套"连线翻转"的点加法，在环面上就是**普通复数加法** `z₁+z₂`。
  "步数世界很干净"的真身就是这个环面
- secp256k1（a=0）有**复数乘法 CM 结构**（藏着复立方根 ω）：
  自同态 `φ(x,y)=(βx, y)`（只一次乘法）等于把点乘上一个大数 λ
  —— 这正是 **GLV 加速**的来源（把 `k` 拆成 `k₁+k₂λ` 并行算，砍一半翻倍）

### 9. 回到最初的问题

随机生成私钥、撞中"地址 ≤ 10000"的概率 ≈ `10⁴ / 2¹⁶⁰ ≈ 6.8×10⁻⁴⁵`。
概率 > 0（理论上存在），但小到物理上等于不可能；且这类小地址被全网机器人
盯着，"中了也藏不住"。靠运气撞出，在数学上等于不可能。
